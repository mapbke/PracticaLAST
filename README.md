# Kurotsuki

Одностраничный учебный магазин интерьерного тюнинга автомобилей в эстетике JDM / anime-inspired atelier. Практика ПМ.09, вариант №5. Проект сохраняет заявки локально; реальной оплаты, рассылки и обратного звонка нет.

[Скриншот светлой страницы](docs/screenshots/light-full.png) · [Протокол проверки](docs/TESTING.md) · [Исходное техническое задание](docs/BRIEF.md)

## Возможности

- 6 услуг, 3 готовых решения, материалы, 8 демонстрационных концептов и подробный featured build.
- Конфигуратор: кузов, объект, материал, строчка, 4 дополнительных опции, количество 1–20.
- Расчёт Flask API, состояния загрузки/ошибки, защита от запоздавших ответов.
- Корзина до 30 позиций: добавление, изменение количества, удаление, повторный серверный расчёт при восстановлении.
- Сохранение корзины и темы в localStorage. Ошибка восстановления не уничтожает сохранённые позиции; доступна повторная попытка.
- Светлая тема по умолчанию, тёмная тема без перезагрузки и вспышки неверного оформления.
- Доступные FAQ, мобильное меню, диалоги с Escape и клавиатурной навигацией.
- Заявка с текущей конфигурацией и корзиной, сохранение в SQLite.
- Пасхалка: три быстрых клика по печати `黒月 / 03` в подвале, затем выбор одного из трёх дизайн-пресетов.

## Технологии

Python 3.11+, Flask 3, Jinja2, SQLite, HTML5, CSS3, Vanilla JavaScript, Flask-WTF, python-dotenv, cryptography, pytest. Node.js 18+ нужен только для дополнительных тестов клиентского состояния. Сборки frontend и npm-зависимостей нет. Проверенная среда: Python 3.12, зависимости из `requirements.txt`.

## Архитектура и структура

```text
app/
  __init__.py       application factory и конфигурация
  routes.py         главная, SEO endpoints, health, 404
  api.py            JSON API, валидация заявки и сохранение
  pricing.py        единый источник тарифов и правил расчёта
  catalog.py        услуги, пресеты, концепты и FAQ
  database.py       соединение SQLite, создание таблицы leads
  security.py       CSRF, HTTPS redirect, защитные заголовки
  templates/        base.html, index.html, 404.html
  static/           CSS, JS, локальные WebP и SVG
scripts/            генератор dev-сертификата
instance/           локальная БД (не в Git)
certs/              локальные сертификат и ключ (не в Git)
tests/              pytest + Node regression tests
docs/               материалы отчёта, аудит, протокол, скриншоты
run.py              HTTP demo
run_https.py        HTTPS demo
```

Клиент хранит `state`, читает форму и отправляет параметры через `fetch`/`async-await`. `renderPrice`, `renderConfigurationSummary`, `renderCart` обновляют DOM. `quoteVersion` не позволяет старому ответу подменить новый расчёт. `cartBusy` сериализует изменения корзины. Сервер считает цену при каждом запросе, включая сохранение заявки; цены из браузера не являются источником истины.

## Локальный запуск — Windows PowerShell

В корне проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000). При уже созданной `.venv` первые два шага не нужны. Если команда `python` отсутствует в PATH, используйте установленный Python 3.11+ по полному пути либо `py -3`.

В активированной среде достаточно:

```powershell
.\.venv\Scripts\Activate.ps1
python run.py
```

Активация необязательна: прямой запуск `.venv\Scripts\python.exe` работает без изменения политики PowerShell. SQLite и таблица `leads` создаются автоматически в `instance/kurotsuki.db`.

Для постоянного ключа сессии скопируйте `.env.example` в `.env` и замените `SECRET_KEY`. Случайное значение можно получить командой `python -c "import secrets; print(secrets.token_hex(32))"`. Без переменной используется временный ключ процесса: после перезапуска сервера открытую страницу нужно обновить, чтобы получить новый CSRF-токен. `.env` не включается в Git.

## Локальный запуск через HTTPS

```powershell
.\.venv\Scripts\python.exe run_https.py
```

Адрес: [https://127.0.0.1:5443](https://127.0.0.1:5443). В активированной среде: `python run_https.py`.

При первом запуске создаются `certs/dev-cert.pem` и `certs/dev-key.pem`, действующие 30 дней для `localhost` и `127.0.0.1`. Это самоподписанный сертификат для демонстрации; браузер не доверяет ему автоматически. Проверка HTTPS выполнена отдельным клиентом с явным доверием только этому сертификату и проверкой имени хоста. Системное хранилище доверия не менялось. После истечения срока переместите старую пару файлов в архив вне проекта и запустите генератор снова.

При демонстрации оставляйте `FORCE_HTTPS=false`. Для включения редиректа задайте `FORCE_HTTPS=true` и HTTPS-адрес в `PUBLIC_URL`: некорректное сочетание отклоняется при старте. Для локального перенаправления с порта 5000 можно использовать `PUBLIC_URL=https://127.0.0.1:5443` и запустить оба скрипта в отдельных терминалах. HTTPS origin имеет отдельную корзину от HTTP origin.

## API

| Метод и путь | Результат |
| --- | --- |
| `GET /` | HTML страницы, CSRF-токен в meta, сессионная cookie |
| `POST /api/calculate` | `200`: конфигурация, название, unitPrice, total, currency |
| `POST /api/contact` | `201`: ID сохранённой заявки, пересчитанный total, сообщение |
| `GET /robots.txt`, `GET /sitemap.xml` | Данные для индексации |
| `GET /health` | `{"status":"ok"}` — доступность процесса, не полный аудит БД |

Оба POST требуют JSON, cookie сессии и заголовок `X-CSRFToken` со страницы. Для HTTPS также используется same-origin Referer, который браузер отправляет автоматически. Ошибка валидации/CSRF — `400`, тело больше 64 KiB — `413`, неизвестная страница — `404`.

Пример конфигурации:

```json
{"carType":"coupe","target":"wheel","material":"leather","stitchColor":"red","centerMark":false,"carbonInserts":false,"perforation":false,"embroidery":false,"quantity":1}
```

Цена этой конфигурации — 30 800 ₽. Формула: `(база объекта + надбавка материала) × коэффициент кузова / 100`, округление вниз до целого рубля, затем доплаты опций; результат умножается на количество. Значения `price`, `unitPrice`, `total` от клиента игнорируются.

Заявка содержит `name`, `contact`, `car_model`, `message`, `consent: true`, `configuration` (объект выше), `cart` (массив конфигураций). При непустой корзине итог равен сумме корзины; текущая конфигурация сохраняется как контекст и второй раз к итогу не прибавляется. При пустой корзине считается текущая конфигурация. Контакт: 7–15 цифр с допустимыми разделителями или `@username` из 4–32 латинских символов/цифр/подчёркиваний с буквой в начале. Проверяется формат, а не существование контакта.

## Безопасность

CSRFProtect, allowlist значений и строгие типы, лимиты количества/длины/тела, параметризованный SQL, Jinja autoescape, DOM через `textContent`, CSP без inline-скриптов, `nosniff`, `DENY`, Referrer-Policy, Permissions-Policy. Cookie: HttpOnly, SameSite=Lax; Secure в HTTPS-режиме. HSTS выдаётся только по HTTPS. Локальная БД, ключи и окружение исключены из Git. [Аудит и ограничения](docs/SECURITY_AUDIT.md).

## SEO и техническая оптимизация

Title, description, canonical, OpenGraph, viewport, семантические секции, один H1, alt, favicon, robots и sitemap. Все 8 изображений локальны, WebP суммарно около 684 KiB. Hero загружается приоритетно, прочие изображения лениво. Основной JS подключён с `defer`; короткий `theme.js` выполняется до CSS для восстановления темы. Используются системные шрифты, внешних CDN нет.

## Production deployment

Скрипты `run.py` и `run_https.py` предназначены для локальной демонстрации. Для WSGI-запуска на Windows в активированной среде доступен `waitress-serve --host=127.0.0.1 --port=8000 run:app`. Для внешнего размещения нужны настроенный reverse proxy с доверенным сертификатом, постоянный SECRET_KEY, PUBLIC_URL, ограничение запросов и политика хранения данных. Если прокси завершает TLS, настройте доверие к его заголовкам по конкретной топологии; иначе приложение увидит HTTP и принудительный редирект зациклится. Не доверяйте произвольным X-Forwarded-* от интернета. [Документация Flask по развёртыванию](https://flask.palletsprojects.com/en/stable/deploying/) и [Waitress](https://flask.palletsprojects.com/en/stable/deploying/waitress/).

Внешнее развёртывание и GitHub push в рамках завершающей проверки не выполнялись. Существующий remote `https://github.com/mapbke/PracticaLAST.git` сохранён, название приложения — Kurotsuki.
