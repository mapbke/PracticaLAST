scripts/generate_dev_cert.py
генерирует локальный self-signed dev certificate.

Файлы:

run_https.py

Чтобы проект можно было запустить локально по адресу:
https://127.0.0.1:5443

ВАЖНО:
это только development HTTPS.
В README честно объяснить, что это self-signed certificate.
Для production рекомендовать настоящий HTTPS через Caddy/Nginx + Let's Encrypt.

Добавить:

в .gitignore

Не коммитить приватный ключ.
