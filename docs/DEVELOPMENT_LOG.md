# Журнал разработки

## Первичная реализация — 10.09.2026

В исходной папке находились README с заданием и Git-репозиторий. Задание сохранено в `docs/BRIEF.md`. Созданы application factory, тарифы, SQLite, API, шаблоны, CSS и Vanilla JS. Подготовлены локальные изображения, dev HTTPS и 40 серверных тестов. Браузерная проверка остановилась на изменении количества корзины.

## Завершающая проверка — 15–16.09.2026

Изучены существующие файлы и Git: проектные файлы ещё не отслеживались, поэтому исходный `git diff` был пустым. Исходные 40 тестов повторно прошли. Приложение продолжено без reset, переинициализации или смены концепции.

В браузере проверены восстановление, количество, форма и размеры экрана. Исправлены: приём телефона из дефисов, отсутствие пересчёта количества во время ввода, совместное сохранение темы/корзины, сохранность подборки при частичном сбое восстановления, сообщения сетевых ошибок, узкая шапка и длинные заголовки, контраст ночного конфигуратора. Добавлены блокировка ошибочной HTTPS-конфигурации и redirect до CSRF на HTTP.

Подключён ранее созданный, но не добавленный в проект JDM moodboard. Остальная концепция и изображения сохранены. Дополнены сводка корзины и поддержка reduced motion при программной прокрутке.

Добавлены 13 серверных регрессий и 8 тестов клиентского состояния. Итог: 53 pytest + 8 Node. Выполнен HTTPS smoke test с проверкой сертификата. Сохранены три полноразмерных скриншота. README заменён инструкцией по запуску; исходный текст задания сохранён отдельно. Подготовлены архитектура, аудит, материалы отчёта и список кадров.
